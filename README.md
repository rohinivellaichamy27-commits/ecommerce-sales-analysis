# E-Commerce Sales & Customer Analysis

## Project Overview

This project analyzes 5,000 e-commerce sales records to identify sales, profit, product, customer, city, payment, and order trends.

## Tools Used

- Excel
- MySQL
- Power BI

## Project Workflow

Excel → Data Cleaning → MySQL → SQL Analysis → Power BI Dashboard

## Key Analysis

- Total Sales and Total Profit
- Category-wise Sales and Profit
- Product-wise Sales and Profit
- City-wise Sales
- Payment Mode Analysis
- Order Status Analysis
- Monthly Sales Trend
- Top 5 Customers

## Power BI Dashboard

The interactive dashboard includes KPIs, sales trends, product and category analysis, city-wise sales, payment modes, and order status.

## Key Insights

- Identified top-performing products and categories.
- Analyzed sales and profitability across cities.
- Compared different payment modes.
- Studied monthly sales trends.
- Identified high-value customers.

## Files Included

- Ecommerce_Sales_Analysis_Dataset.xlsx – Dataset
- ecommerce_analysis.sql – SQL queries
- ECommerce_Sales_Analysis Bi.pbix – Power BI dashboard
